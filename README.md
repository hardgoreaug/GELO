# GELO — proposta de logo

Apresentação interativa do logo GELO em 3D.

- Arraste (mouse ou dedo) para girar; toque duplo / duplo clique volta à pose inicial.
- Botões 1–4 (ou teclas 1–4) trocam a versão de cor sem mexer na posição:
  1. Preto sobre branco
  2. Branco com contorno preto
  3. Branco sobre fundo transparente (quadriculado)
  4. Gelo transparente sobre fogo

O fogo do modo 4 é gerado em tempo real. Para usar uma foto no lugar, coloque um arquivo `fogo.jpg` na raiz do repositório.
